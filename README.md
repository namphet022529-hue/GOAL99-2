# GOAL99 - เว็บไซต์ฟุตบอลครบวงจร (Live Scores, Fixtures, Standings & Analysis)

ระบบหน้าเว็บฟุตบอล **GOAL99** ออกแบบตามมาตรฐาน **Mobile-First** และตรงตามโครงสร้างความต้องการครบทั้ง 22 ข้อ ด้วยธีมสี **เทาเข้ม (#0c0e12, #141720) + แดงเร้าใจ (#e50914) + ขาวคมชัด**

---

## 🌟 ฟังก์ชันเด่นที่พัฒนาเสร็จสมบูรณ์

### 1. โครงสร้างหน้าแรกจัดลำดับใหม่ (Fast Data Access)
- **Header & Brand:** โลโก้ **GOAL99** เด่นชัด พร้อมเมนูหลัก 5 หมวด (ไม่ซ้ำซ้อน):
  1. ⚡ **ผลบอลสด** (Live Scores)
  2. 📅 **โปรแกรมบอล** (Fixtures & Schedule)
  3. 🏆 **ตารางคะแนน** (Standings)
  4. 📊 **วิเคราะห์บอล** (Match Analysis)
  5. ⭐ **รายการโปรด** (Favorites บันทึกด้วย LocalStorage)
- **ช่องค้นหาทีมหรือลีกอัจฉริยะ:** ค้นหาได้ทั้งภาษาไทยและอังกฤษ, ชื่อย่อ, ฉายา (เช่น `แมนยู`, `MUN`, `ลิเวอร์พูล`, `LIV`, `บุรีรัมย์`, `มาดริด`, `La Liga`)
- **แถบเลือกวันแข่งขัน:** 2 วันก่อน, เมื่อวาน, วันนี้, พรุ่งนี้, อีก 2 วัน พร้อมระบุเวลาประเทศไทย (UTC+7)
- **ตัวกรองสถานะ:** ทั้งหมด / กำลังแข่ง (ไฟกระพริบสีแดง) / ยังไม่เริ่ม / จบแล้ว / รายการโปรด
- **ชิปเลือกลีกยอดนิยม:** พรีเมียร์ลีก, ลาลีกา, กัลโช่ เซเรีย อา, บุนเดสลีกา, ไทยลีก 1, ยูฟ่า แชมเปียนส์ลีก และ **🌍 คัดเลือกบอลโลก / เนชันส์ลีก (คู่ในรูปตัวอย่าง)**

### 2. ช่องราคาบอล & ราคาไหล (ตรงตามรูปภาพตัวอย่าง 100%)
- **การจัดคอลัมน์มาตรฐาน:**
  - `[อันดับ] เจ้าบ้าน` | `ราคาบอล (กล่องราคาไหล)` | `ทีมเยือน [อันดับ]` | `สกอร์` | `เวลา/สถานะ`
- **ระบบทีมต่อตัวแดง (Favored Team in Red):** ทีมที่เป็นต่อจะมี **ตัวหนังสือสีแดงและขีดเส้นใต้** ตามธรรมเนียมเว็บบอลไทย เช่น `[158]มอลโดว่า` หรือ `เยอรมนี[13]`
- **กล่องแสดงราคาไหล (Odds Flow Box):**
  - แสดงราคาเปิดและลำดับการขยับของราคา
  - ลูกศรสีเขียว **▲** (ราคาไหลขึ้น / เททีมต่อ) เช่น `▲ 0/0.5`, `▲ 1.5/2`
  - ลูกศรสีแดง **▼** (ราคาไหลลง / เททีมรอง) เช่น `▼ 1.5`, `▼ เสมอ`
- **ปุ่มเปิด-ปิดช่องราคาบอล (Toggle Odds):** สามารถกดปุ่ม `💰 ราคาบอล: เปิด/ปิด` เพื่อสลับมุมมองระหว่างโหมดดูสกอร์อย่างเดียว หรือโหมดตารางราคาบอลได้ทันที
- **บรรจุคู่แข่งขันจากรูปตัวอย่างครบ 10 คู่:**

  2. `[44]เซอร์เบีย` vs `เยอรมนี[13]` (ต่อ) | `1.5/2` -> `▼ 1.5` -> `▲ 1.5/2` -> `▼ 1.5` -> `▲ 1.5/2`

  5. `[43]สก็อตแลนด์` (ต่อ) vs `มาซิโดเนีย[71]` | `1.5` -> `▲ 1.5/2` -> `▲ 2`

### 3. ออกแบบเพื่อมือถือเป็นหลัก (Mobile-First 390px Optimized)
- หน้าจอมือถือกว้าง 390px แสดงข้อมูลทั้งสองทีม สกอร์ เวลา และสถานะได้ครบถ้วนในหน้าจอเดียว **ไม่ต้องเลื่อนซ้ายขวา (Zero Horizontal Scroll)**
- ตารางคะแนนมีระบบเลื่อนแนวนอนเฉพาะภายในตาราง (Internal Overflow Scroll)
- มีแถบเมนูด้านล่าง (Mobile Bottom Navigation Bar) สำหรับการใช้งานด้วยนิ้วโป้งบนมือถือ

### 3. หน้ารายละเอียดคู่แข่งขัน (Match Center Modal)
กดที่คู่แข่งขันใดก็ได้เพื่อเปิดศูนย์ข้อมูลกลางครบทุกมิติ:
- **Hero Scoreboard:** โลโก้ทีม, สกอร์ตัวใหญ่, สกอร์ครึ่งแรก (HT), นาทีแข่งขันสด, และช่องถ่ายทอดสด
- **5 แท็บข้อมูลเจาะลึก:**
  1. ⏱️ **เหตุการณ์สำคัญ (Timeline):** ประตู, คนยิง, คนแอสซิสต์, ใบเหลือง/แดง, การเปลี่ยนตัว
  2. 📊 **สถิติการแข่ง (Match Stats):** แถบเปรียบเทียบการครองบอล (%), โอกาสยิง, ยิงตรงกรอบ, ค่า xG, เตะมุม, ฟาวล์, เซฟ
  3. 👥 **รายชื่อผู้เล่น (Lineups):** แผนการเล่น (เช่น 4-3-3 vs 4-2-3-1), 11 ตัวจริง, ตัวสำรอง พร้อมป้ายระบุสถานะ "ยืนยันแล้ว" หรือ "คาดการณ์"
  4. 🔁 **สถิติพบกัน (H2H):** สรุปผลชนะ/เสมอ/แพ้ และผลงาน 5 นัดหลังสุด
  5. ✍️ **บทวิเคราะห์ & ความโปร่งใส:** แยก **"สถิติจริง (Fact)"** ออกจาก **"ความคิดเห็น (Opinion)"** พร้อมแสดงสถิติความแม่นยำย้อนหลังของนักวิเคราะห์ และปุ่มแจ้งข้อมูลคลาดเคลื่อน

### 4. ระบบความสดของข้อมูลและการแจ้งเตือน (Real-Time Freshness)
- นาฬิกาเวลาประเทศไทย (GMT+7) แบบ Real-time เดินทุกวินาที
- ป้ายสถานะการเชื่อมต่อ: `เชื่อมต่อเซิร์ฟเวอร์สด (Socket Live)`
- มีระบบจัดการเวลาหลังเที่ยงคืนชัดเจน เช่น `พุธ 11 พ.ย. เวลา 01:00 น. (คืนวันอังคาร)` ป้องกันความสับสน
- **ระบบจำลองแข่งสด (Demo Live Simulation):** ปรับนาทีแข่งขันสดอัตโนมัติ และจำลองการทำประตูแบบสุ่ม
- **ระบบเสียงแจ้งเตือนประตู (Web Audio API Synthesizer):** เล่นเสียงกระดิ่งใสเมื่อมีประตูเกิดขึ้น พร้อม Toast แจ้งเตือน (สามารถเปิด/ปิดเสียงได้)
